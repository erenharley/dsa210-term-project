## Project goal

Analyze how political, regional, and global shocks affect tourism demand in Turkey across 15 source markets (2003–2025). The proposal commits to three deliverables:

1. **Market sensitivity** — which source markets over/underreact to which shock type
2. **Recovery rates** — how fast each market bounces back, and whether speed differs by shock or geography
3. **Forward-looking targeting** — actionable recommendations for Turkish tourism firms in the context of **rising MENA tensions (2023+)**

Goal #3 is the headline of the proposal and must be addressed by at least one hypothesis test (see H6).

## Hypothesis tests — lecture-aligned plan (post-redesign)

This plan was reconciled against the course's hypothesis testing lectures (Weeks 4a, 4b, 5a). All tests below are explicitly taught in the lectures, except Pearson/Spearman correlation which is introduced in Week 3a (EDA) as a relationship-quantification tool. **No post-hoc tests (Tukey HSD) are used** — they are not in lecture scope.

| # | Claim | Primary test | Robustness check / fallback |
|---|---|---|---|
| H1 | Market groups respond differently to Turkey's 2016 coup | One-way ANOVA across groups | **Kruskal-Wallis** (lecture-taught non-parametric alternative) |
| H2 | MENA-origin markets fell harder than non-MENA during the Syrian war (2011–15) | **Levene's test** for equal variances → if equal: independent samples t-test; if unequal: **Mann-Whitney U** | — |
| H3 | Recovery speed after COVID differs by group | One-way ANOVA on `years_to_recover` | **Kruskal-Wallis** (small n per group) |
| H4 | Turkey lira weakness correlates with **larger** visitor drops during shocks | Pearson correlation | — |
| H5 | Source country GDP per capita predicts visitor volume | Pearson + Spearman correlation | — |
| H6 | Post-2023 regional tensions reduced MENA-origin tourism more than non-MENA | **Levene's test** → independent t-test OR Mann-Whitney U fallback | — |

**Why no Tukey HSD:** ANOVA is omnibus — it tells you "at least one group differs" but not *which*. Tukey HSD is the standard pairwise post-hoc test, but it is **not in the course's hypothesis testing lectures**. Adding it would be out of scope. Therefore:

- **README claims must stay omnibus.** "Western Europe is most sensitive to the 2016 coup" is a pairwise directional claim that ANOVA alone cannot support — soften to "**Market groups responded differently to the 2016 coup (ANOVA p < α)**" or similar. Do not name a specific group as most/least without a pairwise test.
- Group means may be **described** in the figure as descriptive statistics, but inferential claims about which group is highest/lowest are not allowed.

**Why chi-square is excluded:** considered and rejected. The natural framing (`market_group × recovered_by_2024`) would be a 4×2 contingency table with n=15, giving expected cell counts of ~1.9 — violating the Week 4b validity condition (expected counts ≥ 5 per cell). Skipping chi-square based on this assumption violation is itself a defensible statistical choice that demonstrates engagement with the lecture material.

## Figure design philosophy (post-redesign)

**Every figure must:**

1. Have a **finding-driven title** — a sentence stating what the figure proves, not a description of what's plotted. ❌ "Visitor trends 2003–2025" ✓ "Market groups differed significantly in their response to the 2016 coup (ANOVA p = ___)."
2. Be **visually tied to a single hypothesis test**. The reader should be able to see the test result in the chart, not just the data.
3. Include the **test statistic and p-value** as on-figure annotation (small box, not buried in caption).
4. **Not bend visuals or titles to a desired story.** If a test is non-significant, the title states that honestly. If means look similar, don't dramatize the gap. This is non-negotiable.
5. **Not name specific groups as most/least sensitive in titles** unless a pairwise test backs it (and we don't run pairwise tests). Use omnibus language: "groups differ", "group means vary", etc.

**Style:** light grid, white background, one accent color per market group (consistent across all figures), legible at print size.

## Working principles for in-session edits

- **Verify before claiming.** If a hypothesis test result is being cited (in code comments, README, or figure title), it must come from a test that was actually run on `panel_dataset.csv` in the current repo state, not from memory of a previous run.
- **Regenerate the panel after any pipeline change.** If `01_data_pipeline.py` is edited, run it before running `02_eda_and_hypothesis.py`. Stale CSVs are a silent failure mode.
- **No new data sources without checking academic integrity.** Real API data only. If something is missing from the IMF/WB pulls, fetch it properly, don't hardcode.
- **Stay within lecture scope.** The course teaches: z-test, t-test (one-sample, independent samples with Levene check, paired), one-way ANOVA, two-way ANOVA, Mann-Whitney U, Wilcoxon signed-rank, Kruskal-Wallis, chi-square (goodness of fit and independence). Pearson/Spearman correlation introduced in Week 3a. **Do NOT add tests outside this set without flagging it explicitly.**
